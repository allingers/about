# Beskrivning

En personlig om-mig-sida skapad som en examinerande uppgift i min utbildning till UX Engineer. Sidan presenterar mig, kunskaper och utbildningsbakgrund - byggd med HTML, CSS och vanilla JavaScript.

## Interaktioner

- En textanimation i heron som skriver och suddar ut mina yrkestitlar. Den går att pausa.
- En ”Mer om mig”-knapp som växlar en CSS-klass och visar eller döljer mer text.
- Flikar för kunskaper, styrkor och utvecklingsområden.
- Innehåll som tonas in när besökaren scrollar.
- Kontaktlänkar som öppnar besökarens mejlprogram.

## Tillgänglighet

Sidan använder semantisk HTML, rubriker i ordning och alt-texter på bilderna. Knappar och länkar har synliga fokusmarkeringar, och flikarna går att använda med tangentbordet. ARIA-attribut beskriver interaktionernas lägen för skärmläsare.

Layouten är responsiv och animationerna anpassas efter inställningen för minskad rörelse.
